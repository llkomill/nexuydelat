АНИМАЦИЯ ПОРТРЕТА
=================

portrait.html  — готовая анимация одним файлом: фото И музыка уже внутри.
                 Для GitHub достаточно залить только его. Просто открой в браузере.
index.html     — та же анимация для правок (берёт фото из photo.js, музыку из music.mp3 рядом).
photo.js       — фото, встроенное в base64.
photo.jpg      — исходное фото.
music.mp3      — трек (нужен только для index.html).

МУЗЫКА
------
Браузеры не разрешают включать звук без действия пользователя, поэтому
появится надпись «нажми, чтобы начать» — после нажатия всё стартует синхронно.

Поменять трек в portrait.html: замени music.mp3 и пересобери portrait.html
(вставь в него photo.js и music.mp3 в base64 вместо строки <script src="photo.js"></script>),
либо просто используй index.html + music.mp3 рядом.

Если у трека длинное вступление, поменяй MUSIC_OFFSET в начале скрипта
(с какой секунды трека начинать).

НАСТРОЙКИ (в начале <script>)
-----------------------------
TITLE      — текст надписи
DURATION   — тайминги: пыль, проявление рисунка, полёт частиц, появление надписи
PALETTE    — цвета линий сверху вниз
Клик по экрану — повторить анимацию.
Адрес с ?t=8 в конце — начать с 8-й секунды.
